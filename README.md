# Внутренний вайб — мини-тест

Одностраничный тест из 12 вопросов. Без бэкенда, без зависимостей, без внешних
запросов — весь код внутри `index.html`. Сделан под мобильный экран (в первую
очередь iPhone / Safari).

## Запуск

Открыть `index.html` в браузере. Всё.

## Публикация на GitHub Pages

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: `claude/gift-choice-quiz-2e2pxw`, папка `/ (root)` → Save
4. Через минуту страница поднимется по адресу
   `https://arharovetc.github.io/testimony/`

Этот шаг нельзя автоматизировать: GitHub не даёт токену Actions создать сайт
Pages в первый раз (`Resource not accessible by integration`), включить его
может только владелец репозитория. Дальше всё обновляется само — каждый push
в ветку переопубликует страницу.

## Фото

Положить `p1.jpg` и `p2.jpg` в папку `photos/` — подробности в
`photos/README.md`. Без них страница работает, просто вместо снимков будет
градиент.

## Структура

```
index.html      весь тест: разметка, стили, логика
photos/         картинки для первого экрана и экрана результата
```

## Что внутри

- 12 вопросов, по одному на экран, с прогресс-баром и кнопкой «назад»
- экран подсчёта результата
- 6 вариантов финального результата
- кнопка «Отправить результат»: на iOS открывает системный шэр-шит через
  `navigator.share`, иначе копирует текст в буфер обмена
- поддержка safe-area (чёлка и домашний индикатор), `100dvh`, крупные тап-зоны
