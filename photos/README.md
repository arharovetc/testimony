# photos

Сюда кладутся два файла:

- `p1.jpg` — показывается на первом экране (перед началом теста)
- `p2.jpg` — показывается на экране с результатом

Формат: любой jpg/png, лучше вертикальный (примерно 3:4). Размер — до ~500 КБ,
чтобы страница быстро открывалась на телефоне.

Если файлов нет, страница не ломается: вместо фото рисуется мягкий градиент
с эмодзи. Так что можно залить их и позже.

Имена файлов должны совпадать ровно: `p1.jpg` и `p2.jpg` (строчными буквами).
Если хочется png — поменяй расширение в `index.html` в двух местах (`photos/p1.jpg`,
`photos/p2.jpg`).
